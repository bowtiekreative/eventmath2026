# EventMath — Reserved Keywords

These words can never appear inside a name (event, mark, action, etc.).
Reserved in all forms (no partial match — entire keyword match only).

## Core
`event` `matter` `category` `cat` `layer` `timeline` `action` `door` `open` `closed` `mark` `set` `run` `when` `otherwise` `split` `path` `again` `walk` `end`

## Matter lines
`is` `from`

## Mark / set / calls
`as` `to` `by` `with` `into`

## Loop
`times`

## Timeline sections
`past` `present` `future`

## Time travel
`stop` `break` `add` `remove` `before` `after` `rewind` `forward` `merge`

## Banned surface vocabulary (never in errors or docs)
`parameter` `argument` `callback` `closure` `undefined` `null pointer` `TypeError` `instance` `constructor`
